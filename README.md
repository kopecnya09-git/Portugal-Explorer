# Portugal Explorer

**A Foreign Student's Guide to Exploring Portugal**

Portugal Explorer is an interactive and responsive travel website created as part of an Erasmus internship project. Its goal is to help international students and visitors discover Portugal, explore interesting destinations, and find practical information for their travels.

This project was developed to strengthen frontend development skills, practice responsive web design, and gain experience with version control and website deployment.
It also aims to provide international students with a useful starting point for discovering Portugal.
